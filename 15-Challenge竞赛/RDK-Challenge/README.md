# RDK Challenge 参赛分享：TuntunClaw 家庭物资助手

我们参加了 D-Robotics 发起的 Robotics Dream Keeper Challenge，并基于 RDK X5 完成了 TuntunClaw 家庭物资助手。项目将具身智能仿真、边缘感知、真实机械臂操作、库存记忆和语音提醒串联起来，让机器人能够参与家庭物资管理。

## 项目成果

- 在 MuJoCo 中完成自然语言任务调度、目标理解、抓取位姿推理，以及连续抓取和放置；
- 使用 RDK X5 Magic Box 完成板端感知、相机与语音能力验证；
- 在真实机械臂实验中完成物品取放、库存更新、阈值判断和平板反馈；
- 当库存达到补货阈值时，由 Magic Box 播放语音提醒。

这次挑战让我们把仿真中的具身智能流程真正延伸到边缘设备和真实机器人。RDK X5 提供了实用而有趣的开发体验，也让感知、交互和机器人执行之间的连接更容易落地。感谢 D-Robotics 团队和社区提供这次交流与实践机会。
