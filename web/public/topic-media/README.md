# 展示素材来源

此目录只增加展示用封面、已完成的识别视频与效果图；原有完整录像、报告和失败记录保留原位置。

- `posters/*.jpg`：从对应既有完整视频的第 1 秒抽取，用作加载封面；页面播放入口始终指向完整原片。封面不作为任务成功判据。
- `aura/perception-full.mp4`：Aura 2026-10-20 摄像头闭环访客案例的完整 32 秒识别反馈。人物为仿真角色，实际运行人物检测、人体关键点和 OCR；运动使用运动学适配。原图像识别触发交互，不以预设机器人事件代替识别。
- `aura/ocr.jpg`、`qr.jpg`、`markers.jpg`：标准打印卡片测试输入的实际 OCR、二维码与 ArUco 标注，源自 2026-10-19 教程案例。
- `aura/pose.jpg`：厂商样例图的电脑侧人体姿态结果。
- `aura/gesture.jpg`、`face.jpg`：X5 BPU 在厂商随包图上的手势和人脸关键点结果。
- `aura/depth.jpg`：样例图的相对深度结果，不作为米制测距标定。

其他素材继续使用仓库已有文件或原公开视频地址。`team-learning-data.json` 保存每个案例的运行方式、教程、媒体与多视角关系；`scripts/build-pages.js` 显式收集所有本仓库媒体，包括备选 BPU 录像，避免只复制封面造成播放器缺文件。

## 展示筛选

精选页不收录已知失败的 MicroDuck 扰动基线、提前停止且离目标较远的旧 LightNav 片段、Jumper 近静止基线、Aura 双人主动绕行失败记录或 AMD 未成功回合。正式评测与失败分析仍在原教程中，展示样本不改变评测分母。

地瓜机器人方向包括 MicroDuck 与 Jumper；Aura 和 AMD 为并列方向。GPU 与 X5 BPU 录像为独立执行，切换从头播放；Aura 同一任务的多路相机共用时间轴，切换保留播放位置。
