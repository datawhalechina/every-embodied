## 读报告时关注的字段

| 字段 | 含义 |
| --- | --- |
| `playback_completed` | 控制流程是否执行到底 |
| `safety_stop` | 是否因到位或接触等条件中止 |
| `model_calls_during_session` | 会话中实际新推理次数 |
| `model_induced_command_distance_rad_seconds` | 模型提案引起的控制量变化 |
| `recovery_final_error` | 移琴后腕部位置与方向残差 |
| `onset_metrics` | 实际琴键起音和目标起音的匹配 |
| `performance_passed` | 严格音乐检查结果 |
| `audit_final_qpos_error` | 复核回放与实际执行的最终状态差 |

重新复现时保留自己的报告，不把上述单次运行数值当作所有机器人、曲目和硬件的保证。
