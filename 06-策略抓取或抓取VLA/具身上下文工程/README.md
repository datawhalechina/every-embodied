# 具身上下文工程：让模型在物理世界中观察、行动与验证

本专题研究机器人决策时需要哪些信息、怎样组织与更新这些信息，以及如何将模型输出接入可验证的执行系统。它面向已经了解 Python 和机器人基本概念的读者，连接视觉感知、控制、Agent、世界模型与机器人学习。

## 学习路线

1. [从 Google Gemini 4 Argon 机器人案例理解上下文工程](./01-Gemini-Argon机器人上下文工程案例.md)：阅读 12 个案例，拆解观察、工具、动作、验证与反馈。
2. [机器人上下文设计与实践模板](./02-机器人上下文设计与实践模板.md)：用统一模板设计任务，并在离线记录上检验信息是否足够。
3. 关联实践：[G0.5 机器人弹琴与上下文工程](../大模型控制、VLA、VLM/20-GPT6-Astra机器人弹琴与上下文工程/README.md)，观察琴位变化、重新定位和续弹中的状态更新；[Agnes Harness 多设备 Demo](../大模型控制、VLA、VLM/11Agnes-Harness多设备Demo/README.md) 展示工具与状态编排。

## 核心问题

- **观察**：任务指令、相机图像、机器人状态、坐标系和时间戳中，哪些信息对当前动作必要？
- **记忆**：任务目标、已完成步骤、失败原因和环境变化如何更新，何时重新观察？
- **行动**：可调用哪些工具和动作原语，输入的坐标、单位与约束是什么？
- **验证**：用什么证据判断动作完成、接触发生或目标达成？失败后怎样恢复？
- **预算**：在哪些关键节点需要更多观察与推理，如何权衡延迟和效果？

上下文工程描述的是为决策准备和维护信息的方式；Harness 则负责工具接口、执行、状态管理与验证。二者协作，但无法仅凭提示词替代标定、控制器或安全机制。本专题首版以案例和设计练习为主，未复现 Google 的实验。
