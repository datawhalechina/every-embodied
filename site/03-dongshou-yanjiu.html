1. 三条动手路线

1.1 MuJoCo + LeRobot：最轻的入门路线

适合：想先理解动作块、策略训练与评估脚本的人。

  • 环境：Python 3.10、MuJoCo 3.1.6；LeRobot 建议固定 commit，直接 pip install 可能报错。
  • 数据：自采 MuJoCo 遥操作数据，或使用 Datawhale 的 20 episodes / 2621 帧小数据集。
  • 策略：ACT（51.55M，30–60 分钟可训）、SmolVLA（450M）、π0（依赖 PaliGemma）。
  • 参考：LeRobot 教程、ACT 结构。

最小目标：采 20–50 条轨迹，跑通 ACT 训练与评估；不要用单条轨迹下结论（std=0.001 会放大噪声）。

1.2 OpenVLA + LIBERO：理解 7B VLA 的部署链路

适合：想看大模型权重、LIBERO 评测与显存/兼容性问题的人。

  • 权重：openvla/openvla-7b 及四个 finetuned-LIBERO 权重；代码 openvla/openvla。
  • 显存：章节记录约 10.3GB。
  • 坑：LIBERO 的 torch.load pickle 错误需要修；EGL Context Error 可忽略。
  • 参考：OpenVLA 复现。

最小目标：跑通一条 LIBERO rollout，确认 Success: True；不要期待章节给出完整成功率。

1.3 Harness + RPent / RoboDojo：理解“不改模型也能涨点”

适合：想看编排层、记忆、解析原语与评测协议的人。

  • 最省事入口：RPent（pip install -e ".[libero-pro]"），它把 harness 做成 CLI + Dashboard + 文档。
  • RoboDojo（可选，重）：Isaac Sim 5.1 / IsaacLab、Python 3.11、ARX-X5 双臂、Pi0.5；42 个任务分五类；成功判定在 result.json。实验性接入，尚无完整套件成功率。
  • 参考：用户提供的 Harness 调研（S22）与 RPent RoboDojo 文档（S23）。

最小目标：跑 1 个 LIBERO-Pro 任务，观察 command.json / state_NN.json；或跑 1 个 RoboDojo 任务，先检查 environment_result_available=true 与 agent_error_present=false，再看 success。

2. 三个最小实验

实验 A：ACT 的数据量与动作块

  • 变量：轨迹数（10 / 20 / 50）、chunk size（1 / 10）。
  • 观察：成功率、动作平滑度、训练时间。
  • 目的：理解“小数据 + 动作块”何时够用，何时开始过拟合。

实验 B：SmolVLA / π0 的 smoke test

  • 步骤：加载 base 模型 → 1 step 训练 → 保存 checkpoint → 评估脚本跑通。
  • 注意：配置解析通过不代表完整训练已验证；π0 依赖 PaliGemma，权重与显存要先确认。
  • 目的：建立“能加载、能训练、能评估”的最小闭环，而不是复现论文分数。

实验 C：harness 的增益来自哪里

  • 三组：纯 ACT / ACT + 解析原语 / ACT + 解析原语 + TSM 记忆。
  • 观察：成功率、调用分布（vla_act vs 解析原语）、位置交换与指令重定向的差异。
  • 目的：拆开“记忆”和“解析原语”的贡献；这正是现有 harness 论文没有拆开的消融。

3. 复现边界清单

读任何 VLA 论文，先问五个问题：

  1. 代码：官方仓库是否存在？是完整实现还是骨架？
  2. 权重：是否公开？是否 gated？是否需要同意非商业许可？
  3. 数据：训练数据是否公开？是完整数据、子集，还是只给统计量？
  4. 训练配方：超参、数据配比、评测脚本是否公开？是否依赖内部集群？
  5. 部署栈：论文里的延迟/加速比是否有对应公开代码？还是只存在于公告？

再加三条：

  • 算力：PRTS 用 64 张 H100，Agentic-VLA 用 4 张 A100，3DVLA 用 4 张 A800，DiT4DiT 建议 ≥48GB 显存，G0.5 全量微调 >70GB。先看自己有没有对应资源。
  • 评测协议：LIBERO 子套件、rollout 数、no-noops、RoboTwin Easy/Hard、RoboDojo 任务类别，都会改变结论。
  • 安全：EVA-Client 不提供自动运动安全保证；LWD 依赖人类接管；Dexora 列出指令歧义、相似物误判、摩擦不足、双臂不同步等失败模式。

4. 研究空位：可以做什么

  1. 3DGS-native 轻量 VLA：用 CompactSplat 式前馈高斯做输入或辅助 loss，配 0.5–1B 策略，验证“3D 上下文能否替代参数规模”。
  2. RVQ-head 的系统比较：目前只有 G0.5 一条本地证据；比较 RVQ、FAST/BPE、flow matching 在延迟、精度、跨本体上的差异。
  3. 轻量 VLA 的跨本体极限：0.5B 能做到什么程度的本体泛化？Evo-1 0.77B 与 EffVLA 3.75B 是两个锚点，但中间地带没有系统研究。
  4. 闭环量化标准：VLAQuantBench 只做 PTQ；QAT 与 WAM 量化还没有人做。
  5. WAM 的推理成本-收益曲线：1B WAM 已出现，但“想象几步最划算”没有公开答案。
  6. 3DGS 数据引擎的规模化：LEGS 证明单场景有效；多场景、跨本体的数据引擎经济学没有。
  7. harness 的可验证性：HarnessEval-W 是唯一把 harness 本身当评测对象的；记忆容量-泛化权衡、planner token 成本、与 RL 的结合都还开放。
  8. RoboDojo 榜单与协议：42 任务五类、Pi0.5 14 维、result.json 判定已明确；完整套件成功率与榜单排名仍缺。

5. 自测题

  1. VLA 与 VLM 的输出差异是什么？
  2. RT-1 的 256 bins 与 RT-2 的文本 token 有什么共同点与差异？
  3. 为什么 OpenVLA 选择 7 维连续动作，而不是文本 token？
  4. ACT 的 chunk size 解决什么问题？过大会怎样？
  5. RVQ 与 FAST/BPE 都是动作 tokenizer，核心差异是什么？
  6. 3DGS 在 VLA 里目前最常见的三种角色是什么？
  7. 为什么 3DGS 很难直接当视觉塔？至少说两个原因。
  8. World-Action Model 与纯视频世界模型的区别是什么？
  9. Harness VLA 的 84.2% 解析原语说明什么？它没有说明什么？
  10. 为什么 LIBERO 的成功率不能直接和 RoboTwin/RoboDojo 横比？

参考答案要点：

  1. VLM 输出文本/多模态 token；VLA 输出动作或动作块。
  2. 都把动作变成可生成的离散序列；RT-1 是分类 bin，RT-2 复用语言词表。
  3. 连续动作更平滑、低延迟，适合高频控制；但也更难建模多峰分布。
  4. 一次预测多步，降低累积误差与推理频率；过大会增加执行误差与反应延迟。
  5. RVQ 是残差向量量化、多轮精修；FAST 是 DCT + BPE 的频域压缩。
  6. 数据引擎、场景表示、世界模型（以及轻量化 3D 表征）。
  7. 渲染慢、显存大、梯度到动作的链路长；现有工作更倾向训练期蒸馏或外部表示。
  8. WAM 联合预测未来与动作；视频世界模型只生成未来观测，不直接输出动作。
  9. 说明大部分执行是确定性脚本；没有说明记忆、规划和策略本身谁贡献了多少。
  10. 子套件、rollout 数、no-noops、Easy/Hard、仿真/真机与任务类别都不同。

6. 常见误区

  • 把本目录导读当成论文原文；导读已经做过一次筛选与转述，本文又做了第二次。
  • 把不同工作的 LIBERO 成功率直接横比，忽略子套件、rollout 数与 no-noops。
  • 把“代码公开”当成“结果可复现”，忽略权重、数据、训练配方与部署栈。
  • 把官方公告里的加速比或成功率当成独立复现结果；DM0.5 的 9.29× 是典型例子。
  • 把本目录 2026 年的选题聚类当成 VLA 领域的真实时间分布。
