# 一起做一台能看、能回应、能交接家务的 Aura

这次组队学习从 FrontierX Aura 的供电、联网和 SDK 开始，逐步实现举手与卡片识别、圆屏语音反馈、家庭巡游和近人停车，再理解 Aura 如何把“帮我收拾垃圾”交给同一家庭里的 R1 Pro 执行。

课程为 14 天，建议 3–5 人组队。懂 Python 基础即可开始；没有机器人也能运行六篇 Notebook、公开证据审计、协议与检查点测试。拥有 Aura 的小组可做现场感知与交互，拥有 GPU 工作站与授权资产的小组可复现原生移动操作。

完成后将得到一套能继续扩展的代码框架、清楚的接口边界、可追溯的失败分析，以及完整第三视角、机器人相机和全屋俯视展示。课程提供 11 路完整视频、关键帧、结构化事件和三罐验收文件。

学习成果侧重“看得见、查得到、接得上”：相机触发要有帧证据，模型调用要有公开摘要和工具回执，任务完成要有独立条件，恢复后要接着做。我们一起把可展示的机器人，做成可复现的工程。
