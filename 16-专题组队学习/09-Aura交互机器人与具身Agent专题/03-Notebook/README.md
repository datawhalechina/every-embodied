# 六个可在 CPU 上运行的 Notebook

按序运行，每篇只使用 Python 标准库和本课程公开数据，不访问真机、不调用模型、不下载资源。Notebook 中的教学数值均明确标成示例；实际验收从 JSON 读取。

1. [SDK 与资料审计](01_SDK与资料审计.ipynb)
2. [RGB-D 坐标与量纲](02_RGBD坐标与量纲.ipynb)
3. [相机事件与状态机](03_相机事件与状态机.ipynb)
4. [数字孪生资源检查](04_数字孪生资源检查.ipynb)
5. [三罐结果与工具合同](05_三罐结果与工具合同.ipynb)
6. [检查点与自动继续](06_检查点与自动继续.ipynb)

可在 Jupyter/VS Code 打开；代码通过向上查找 `media-manifest.json` 定位课程，不要求个人电脑的绝对路径。真实设备入口在章节中单列，默认练习不会发送运动命令。
