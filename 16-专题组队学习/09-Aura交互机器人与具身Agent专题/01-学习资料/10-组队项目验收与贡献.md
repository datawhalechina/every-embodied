# 10 组队项目、验收矩阵与开源贡献

建议 3–5 人一组、14 天完成：一人负责设备/SDK，一人感知与交互，一人仿真与相机，一人 Agent 和恢复，一人复核资料与视频；人数较少时合并角色。每项提交由另一位成员使用清单复核。

## 10.1 三条可选择的学习路径

**无硬件路径**：运行 Notebook、公开证据审计、事件播放器、MuJoCo 模型检查，并实现状态机和恢复练习。输入来源写成公开录像或仿真帧。

**Aura 真机路径**：在上述基础上完成供电/联网、SDK、新鲜相机、举手/卡片、屏幕和语音通路；运动演示从短时限速开始，分别记录设备和算法侧输出。

**工作站进阶路径**：准备有授权的原生家庭资产和现有隔离环境，接同场景人/Aura/R1、RGB-D 工具、三罐投放、成对恢复与多视角视频。重用已完成前缀，保留恢复边界。

## 10.2 本专题的验收矩阵

| 能力 | 本项目当前证据 | 学习小组提交 |
| --- | --- | --- |
| 供电联网 | 样机更换供电后恢复，局域网 SDK 可读 | 故障记录和 probe |
| 相机 | 真机新鲜图、仿真原生相机 | 双帧与时间戳 |
| 卡片/举手 | 相机闭环正例与负例 | 事件、原帧、误触发表 |
| 麦克风 | 真机近无声问题保留；仿真 ASR 使用合成输入 | 原音频、RMS、ASR 来源 |
| 电池 | 扩展可读电压；SOC/charging 未标定 | 原始回包和缺失项 |
| Aura 导航 | 已知图、理想定位、原生车轮巡游 | 实际轨迹和静态障碍 |
| Aura 近人处理 | 已验证停车、等待、恢复 | 前后观测与停止日志 |
| Aura 双人主动绕行 | 历史实验未完成验收，选做 | 新实验独立报告 |
| R1 三罐 | 原生 Inside、释放、稳定与任务谓词通过 | 相机、工具与验收关联 |
| R1 返回 | 最终位置、距离、停稳通过 | 独立返回证明 |
| R1 行人动态绕行 | 独立算法专题，不在本课必做范围 | 无必做要求 |

完整教程的含义是入口、步骤、结果和未验证范围都能追溯；不把表中的未知项填成已通过。

## 10.3 课程项目建议

**基础项目：会看卡片的桌边 Aura。** 展示文字，确认人物举手，屏幕反馈读到的内容；遮挡或空白卡不得误触发。提交两路完整视频和事件。

**导航项目：房间巡游讲解员。** 有效卡片授权后，Aura 在已知图中访问三站，遇人停车，路通后继续；结果报告附站点日志。选做主动绕行，但不影响基础项目验收。

**综合项目：家务交接员。** 人招呼 Aura，Aura 找人并交接给 R1；R1 跨房间搜索与收集三罐，返回后 Aura 报告。提交五路完整视频、公开工具日志、三罐与返回证明、一次恢复记录。

**工程项目：失联后的可恢复系统。** 在不运行物理环境时测试记录缺失、校验失败、重复请求与过期帧；原生运行时只对本组任务注入工具边界中断，不操作其他任务。

## 10.4 视频交付要求

保留完整第三视角和机器人视角；复杂房间再交付全屋俯视。所有视角使用同一时间轴，切换不跳过失败、等待或恢复；封面动图注明节选。保留音轨说明，给出分辨率、帧数、仿真频率、编码帧率与 SHA256。

本课程的五路完整家庭录像各 2557 帧、255.7 秒；详情见 [`media-manifest.json`](../media-manifest.json)。较短的 GitHub 动图便于浏览，完整 MP4 在同仓 Release 中保存，避免把大视频反复写进 Git 历史。

## 10.5 提交到开源仓库

只提交本专题的正文、源代码、测试、图片和轻量索引；大资产、权重、登录凭据、个人网络信息与缓存留在个人环境。提交前运行 `course_lab.py audit`、单元测试、Notebook 和相对链接检查，再检查实际 GitHub 页面中的图片和视频入口。

PR 描述写清楚任务触发、结果行为、输入来源、验证命令和未测范围。增量改进用新目录/新版本，已验收录像、证明与图像保留，不把旧失败记录覆盖成成功。

## 10.6 评分建议

设备/离线入口 15 分，感知与负例 20 分，交互与交接 15 分，Aura 导航 15 分，Agent 合同与恢复 20 分，证据与教程 15 分。无硬件组可用等价的公开帧回归和协议测试替代现场采集，提交时明确路径；额外原生三罐项目作为综合展示，不挤占基础学习进度。
